# WISE² CARTOOLS — Playable World 01
Development-only browser 3D prototype integrated into the WISE² GTA6 Atlas repository.
Run: cd world && npm ci && npm run dev
Build: cd world && npm run build
Controls: WASD / arrow keys or mobile direction buttons; E / ACTION near the glowing mission ring.
Current features: procedural city, third-person player, mission marker, HUD, vehicle prop.
Not yet implemented: driving, multiplayer, realistic character assets, collision physics, Unreal Engine 5 port, production deployment.
Hermes brief: docs/HERMES_GAME_BUILD.md
This is original game content, not a Rockstar/Grand Theft Auto game.
